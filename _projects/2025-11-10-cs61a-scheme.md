### Introduction
Implemented a full interpreter for a functional programming language inspired by Scheme. The system supports lexical scoping, recursive evaluation, user-defined procedures, and environment frame manipulation. The goal was to design a modular evaluation engine capable of interpreting complex expressions.

### Skills
- Python
- Interpreter Design
- Recursive Evaluation
- Lexical Scoping
- Abstract Syntax Tree Handling

### Implementation

- Built an expression evaluator supporting atoms, lists, procedures, lambdas, and special forms.
- Implemented dynamic environment frame creation and variable binding.
- Designed call-frame chains to support closures and recursive function execution.
- Added support for tail-call optimization patterns and user-defined macros.

### My Role
- Developed the core eval/apply cycle.
- Implemented procedure objects and lambda evaluation.
- Debugged scoping bugs involving nested environment frames and closures.

### Insights
- Learned how interpreters transform abstract rules into executable semanticsz.
- Deepened understanding of recursion and scope management.
- Improved debugging skills around runtime evaluation flows.
