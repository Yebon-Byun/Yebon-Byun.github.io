### Introduction
Developed a clean and deterministic logic engine for the 2048 puzzle game, focusing on tile movement, merge rules, and dynamic board updates. The project emphasized separation of UI and game logic for modularity.

### Skills
- Java
- Object-Oriented Programming
- Game Logic
- State Management
- Algorithm Design

### Implementation
- Built a board abstraction representing grid tiles and merge behaviors.
- Implemented directional movement with tile compression and merging rules.
- Designed scoring logic and end-game state detection.
- Added a predictable update cycle for consistent gameplay behavior.

### My Role
- Implemented the full movement/merge algorithm.
- Optimized grid update operations to reduce redundant computations.
- Developed scoring and win/loss detection logic.

### Insights
- Learned the value of separating core game logic from rendering.
- Improved understanding of efficient 2D grid manipulation.
- Gained experience building deterministic game engines.
