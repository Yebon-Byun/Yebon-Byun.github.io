### Introduction
Built a real-time typing game that evaluates speed and accuracy based on live user input. The project involved designing algorithms for typo detection, string comparison, and performance scoring.

### Skills
- Python
- Algorithms
- Text Processing
- Real-time Input Handling

### Implementation
- Developed a scoring algorithm based on edit distance to measure typing accuracy.
- Combined WPM and error rate to compute a holistic performance score.
- Implemented a sentence selection engine that adjusts difficulty dynamically.
- Built a real-time comparison engine to analyze user input as they type.

### My Role
- Implemented the typo-detection and accuracy scoring algorithms.
- Designed the combined speed/accuracy scoring model.
- Optimized sentence selection to reduce latency.

### Insights
- The project reinforced how much algorithmic efficiency impacts user experience, even in text-based applications.
- Choosing the right comparison algorithm dramatically improved responsiveness and accuracy.
