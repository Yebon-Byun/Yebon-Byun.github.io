### Introduction
Built a generic double-ended queue (deque) supporting constant-time insertion and removal at both ends. Designed the API and internal structure to be efficient, robust, and iterable.

### Skills
- Java
- Data Structures
- API Design
- Performance Engineering
- Unit Testing

### Implementation
- Designed a circular array for O(1) push/pop operations.
- Built a linked-node variant for flexible memory behavior.
- Implemented iterator support for sequential traversal.
- Wrote comprehensive tests for boundary conditions and resizing logic.

### My Role
- Authored the full deque API.
- Implemented dynamic resizing for amortized constant-time performance.
- Ensured correct pointer handling and memory stability.

### Insights
- Strengthened understanding of array vs linked implementations.
- Learned how to build reliable, low-level data structures.
- Improved ability to reason about algorithmic performance.
