### Introduction
Developed an analysis tool that integrates historical word frequency datasets with graph-based semantic relationships. Used to explore trends, neighborhoods, and linguistic structures.

### Skills
- Java
- Graph Theory
- File Parsing
- Lightweight NLP
- Query Engine Design

### Implementation
- Built a directed graph representing word relationships.
- Parsed large-scale frequency datasets and mapped them to graph nodes.
- Implemented query functions combining graph traversal with frequency analysis.
- Designed API endpoints for word trends and semantic neighborhood queries.

### My Role
- Implemented graph construction and traversal algorithms.
- Integrated frequency data into the search pipeline.
- Optimized queries for performance on larger datasets.

### Insights
- Learned how graph structures can model semantic information.
- Improved data parsing and integration skills.
