### Introduction
Reimplemented the historical Enigma encryption machine as a software-based cipher simulator. The project required modeling mechanical components—rotors, reflectors, and plugboards—as interacting software objects. The focus was faithfully reproducing the device’s dynamic state transitions and rotor-based encryption rules.

### Skills
- Python
- Cryptography Fundamentals
- Object Composition
- State Machine Modeling
- Systems Design

### Implementation
- Modeled Rotors, Plugboard, and Reflector as separate objects with clear responsibilities.
- Implemented rotor rotation rules and notch mechanics to mimic the original hardware.
- Designed bidirectional signal paths to mirror true Enigma encoding.
- Built a full state machine to handle dynamic rotor positions on every keypress.

### My Role
- Designed the Rotor/Plugboard component architecture.
- Implemented the end-to-end signal routing and encoding logic.
- Debugged multi-rotor interactions and ensured consistent rotation behavior.

### Insights
- This project showed how hardware systems can be abstracted into predictable state transitions.
- It deepened my understanding of system modeling and strengthened my ability to translate physical mechanisms into software logic.
