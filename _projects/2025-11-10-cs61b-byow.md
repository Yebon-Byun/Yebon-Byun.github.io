### Introduction
Developed a tile-based world generation engine featuring procedural map creation, randomization, and real-time exploration. The system focuses on algorithmic generation and stateful world simulation.

### Skills
- Java
- Game Engine Architecture
- Random Algorithms
- State Persistence

### Implementation
- Built a grid-based world using rooms, hallways, and terrain tiles.
- Implemented seeded randomness for reproducible world generation.
- Designed an interactive rendering engine and movement system.
- Added world saving and loading functionality for persistent gameplay.

### My Role
- Implemented the room/hallway generation algorithm.
- Developed the state persistence system.
- Improved rendering performance and edge-case handling.

### Insights
- Gained experience designing procedural generation systems.
- Learned techniques for debugging randomized logic.
- Understood how engine, rendering, and persistence layers interact.
