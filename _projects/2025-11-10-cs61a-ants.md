### Introduction
Developed a Python-based strategic simulation game involving resource management and real-time decision making. The system models interactions between ant units and invading insects, each with distinct behaviors, abilities, and constraints. The core challenge was designing an event-driven architecture that coordinates complex unit interactions across a dynamic environment.

### Skills
- Python
- Object-Oriented Programming

### Implementation
- Designed unit archetypes (e.g., Soldier, Harvester) using an inheritance-based class hierarchy.
- Modeled movement, combat, and side effects using sequential event loops.
- Represented the map with Tunnel/Colony objects to simulate environments.
- Added special behaviors using lightweight mixin-style extensions for flexible action logic.

### My Role
- Designed and implemented new ant unit behaviors.
- Refactored core Colony/Place structures for clearer state management.
- Resolved edge cases in the combat engine (simultaneous attacks, timing conflicts) to balance gameplay.

### Insights
- This project taught me the importance of breaking down complex systems into modular components.
- Combining inheritance with composition patterns was especially effective for building a flexible and maintainable simulation.
