### Introduction
Developed a hybrid mobile application for both iOS and Android platforms, designed to support a local community with multimedia services, notifications, and interactive resources. The app features multiple navigation tabs, including video content, hymns, service sections, and announcements.

### Skills
- HTML / CSS / JavaScript  
- React Native  
- Node.js  
- Flask  
- MongoDB  
- AWS  
- Docker  
- FileZilla  
- UI/UX Design  

### Implementation
- Designed and developed UI/UX components including loading screens, home screens, notification systems, and multi-tab navigation.
- Built frontend views with React Native and integrated backend APIs built using Node.js and Flask.
- Configured MongoDB for data storage and content retrieval.
- Deployed backend services on AWS and containerized components using Docker.
- Utilized FileZilla for media and resource transfers, ensuring smooth deployment to production environments.
- Optimized cross-platform compatibility and ensured consistent performance on both Android and iOS.

### My Role
- Designed the UI/UX and developed both frontend and backend features.
- Conducted demographic and user behavior research, focusing on usability for older adults (50+).
- Coordinated communication between ACAST and the client organization, preparing feature roadmaps, progress updates, and delivery schedules.
- Collaborated closely with senior engineers to align system architecture and deployment pipelines.

### Insights
- Gained hands-on experience developing hybrid mobile applications for multi-platform environments.
- Learned the importance of accessibility and intuitive UI when targeting older user groups.
- Strengthened full-stack development skills through API integration, cloud deployment, and interactive UI engineering.
- Realized the value of structured communication in client-facing development workflows.

### Additional Note
Although the application was successfully released on the Google Play Store and Apple App Store, it has been temporarily withdrawn due to internal company circumstances.
